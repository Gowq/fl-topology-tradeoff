# Exp. 08 - TimeTrojan topology comparison

Exp. 08 tests whether the HFL/VFL topology changes resistance to the same modern
time-series backdoor. The attack is generated upstream, before the federated
partition, and the frozen poisoned windows are reused by every HFL and VFL cell.

## Scope

- Attack: TimeTrojan-FGSM transfer generated by one centralized surrogate per
  dataset/seed.
- Poisoning: dirty-label, 5% additional poisoned training windows, target class
  1, K=5 temporal positions, eta=2.0, 10 refinement iterations.
- Surrogate: centralized single-branch DeepConvEncoder family from Exp. 06,
  trained without DP only to generate the trigger.
- Primary comparison: HFL/FedAvg versus VFL/coordinator.
- Secondary HFL defenses: FLTrust and FoolsGold.
- DP regimes: no DP, epsilon=20, epsilon=100, delta=1e-5, clipping C=5.
- Datasets: MHEALTH and OPPORTUNITY.
- Holdout: cross-subject in both datasets. MHEALTH trains on subjects 1-8 and
  tests on subject 10; OPPORTUNITY trains on S1/S3/S4 and tests on S2.
- Seeds: five paired primary seeds, first three reused for secondary defenses.
- Training: 25 rounds, 3 local epochs, no early stopping, final round is primary.
- Main endpoint: `ASR_uplift = ASR_poisoned - ASR_clean` on the same triggered
  non-target test windows.

The topology effect is `delta_topologia = ASR_uplift_HFL - ASR_uplift_VFL`.
Positive values mean VFL is more resistant; negative values mean HFL is more
resistant.

## Commands

List the 384 federated jobs:

```bash
bash scripts/run.sh exp08 --list
```

Prepare the 10 frozen attack artifacts:

```bash
bash scripts/run.sh exp08 --prepare-all-artifacts
```

Run one federated job:

```bash
bash scripts/run.sh exp08 --config-index 0
```

Analyze complete or partial results:

```bash
bash scripts/run.sh exp08-analyze --allow-partial
```

## Gate

Before launching the complete matrix, use seed 42/no-DP/intermediate results to
check:

- surrogate validation ASR >= 80%;
- transfer ASR >= 50% in at least one topology;
- ASR uplift >= 20 percentage points in at least one topology;
- clean macro-F1 drop no worse than 5 percentage points;
- identical artifact hashes in paired HFL/VFL cells.

If the gate fails, the full Exp. 08 matrix should not be interpreted as a valid
TimeTrojan transfer test.

The primary analysis reports dataset-level and condition-level paired summaries.
These are indicative because the primary arm has five seed clusters. The
secondary FLTrust/FoolsGold arm is HFL-only with three seeds and is reported
descriptively, not as a causal HFL-versus-VFL topology comparison.

The completed matrix passes the gate on OPPORTUNITY. MHEALTH fails the
clean-utility criterion because the selected HFL condition loses 10.9 percentage
points of clean macro-F1; its TimeTrojan results must therefore be treated as
exploratory. The frozen-artifact hash check passes for all paired topology cells.
